# 时间守护者 TimeKeeper 微信小程序版

这是一个可导入微信开发者工具或扣子编程的微信小程序项目。

本版本是“扁平导入版”：解压后只有一个主文件夹，主文件夹内不再包含子文件夹，页面入口为 `index`。

## 已实现功能

- 首页、计划、统计、我的四个页面
- 自然语言添加任务，例如：`写报告2小时，上午完成`
- 一次输入多条任务，例如：`写报告2小时，开会1小时，运动30分钟`
- 支持带编号的计划，例如：`1. 8:00-10:00 写方案 2. 10:30-11:00 开会`
- 自动按优先级和截止偏好排期
- 任务开始、完成、编辑、删除
- 今日完成率、计划时长、优先级分布统计
- 工作时段设置
- 本地数据保存
- 将任务写入手机日历提醒

## 关于手机闹钟

微信小程序通常不能直接控制手机系统闹钟，也不能像 Android 原生 App 一样长期后台运行。

当前版本使用可行替代方案：在任务时间线里点击“加入手机日历提醒”，通过 `wx.addPhoneCalendar` 把任务写入手机日历，由手机系统日历发出提醒。

如果一定要直接联动手机闹钟或检测 App 使用时长，需要开发 Android 原生 App，并接入系统权限。

## 导入微信开发者工具

1. 安装并打开“微信开发者工具”。
2. 选择“导入项目”。
3. 项目目录选择本文件夹：`timekeeper-wechat-miniprogram`。
4. 没有小程序 AppID 时，可先选择测试号/游客模式预览。
5. 如果已有小程序账号，把 `project.config.json` 里的 `appid` 改成你的真实 AppID。
6. 点击“编译”，即可在模拟器里查看。
7. 点击“预览”，扫码可在手机微信里体验。

## 发布为正式微信小程序

1. 注册微信小程序账号并完成认证。
2. 在微信公众平台获取 AppID。
3. 将 `project.config.json` 中的 `appid` 替换为真实 AppID。
4. 在微信开发者工具中上传代码。
5. 在微信公众平台提交审核。
6. 审核通过后发布。

## 使用提醒

- 数据保存在微信本地缓存中，换手机或清理微信缓存后数据不会自动同步。
- 日历提醒是否成功，取决于手机系统和微信权限。
- 如需云同步，需要再接入云开发或后端数据库。
